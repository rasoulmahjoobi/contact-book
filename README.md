# Contact Book

A simple and responsive contact management web application built with React and JavaScript. The project focuses on component-based development and creating a clean, user-friendly interface for managing contact information.

## Tech Stack

- React
- JavaScript
- Tailwind CSS
- React Icons
- HTML5
- CSS3

## Features

- Contact management interface
- Component-based React architecture
- Responsive user interface
- Reusable React components
- Styled with Tailwind CSS
- Icon-based UI elements with React Icons

## Getting Started

### Prerequisites

Make sure you have Node.js installed on your machine.

### Installation

Clone the repository:

git clone https://github.com/rasoulmahjoobi/contact-book.git

Navigate to the project directory:

cd contact-book

Install dependencies:

npm install

Start the development server:

npm start

The application will be available at:

http://localhost:3000
